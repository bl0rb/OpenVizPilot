# ee-stub

Vorlage für den Enterprise-Stub im öffentlichen Repo (`bl0rb/OpenVizPilot`): `scripts/core-export.sh`
kopiert diesen Ordner beim Core-Export nach `ee/`, wo er das echte `ee/` (Enterprise Edition) ersetzt.
Kein npm-Workspace, keine eigene Lizenz — dieser Code ist Core und steht unter der Root-`LICENSE`.

Die vollständige Enterprise Edition (SSO, User-Memory, gespeicherte Abfragen, MCP, Tableau Server,
Lizenz-Aktivierung) liegt im privaten Repository `bl0rb/OpenVizPilotEnterprise`; siehe
[docs/enterprise.md](../docs/enterprise.md).
